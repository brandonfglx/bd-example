Hello, welcome to bd-example, a basic showcase of the capabilities of bd.

## About
`bd` is a simple command line interface program written in rust that helps simplify the creation of static HTML websites. You can learn more about `bd` [here.](https://github.com/brandonfglx/bd)

## Markdown
Since `bd` uses a markdown engine to help render into HTML, there is no need to write convoluted tags like:
```html
<!DOCTYPE html>
<html>
	<head>
		<title>Hello, World!</head>
	</head>
	<body>
		<h1>Hello, World!</h1>
	</body>
</html>
```
Instead, everything you need can be found in any one of the thousands of markdown guides on the internet.

## Publishing
Since `bd` relies on git, a version control manager, to manage its files, you need to have it installed on your local machine.

Lucky for you, `bd` automatically manages the publishing of the entire website or singular pages using `bd publish`.

## What's Next?
`bd` is still in its alpha phase, which means that the user experience is degraded compared to a stable or beta release. Do not expect certain features to function properly or be implemented.
